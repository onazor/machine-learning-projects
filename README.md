# Machine Learning Projects

A collection of applied machine learning projects that turn customer and transaction data into practical marketing decisions. Each project includes a Jupyter notebook, its source data, and a presentation that summarizes the analysis for a business audience.

## Projects

| Project | Problem | Approach | Key outcome |
| --- | --- | --- | --- |
| [Campaign Analysis](campaign-analysis/) | Decide which customers should receive a gold-membership sales call | Classification, model tuning, ensembling, and customer ranking | A soft-voting model captured 73.1% of historical responders in the top 20% of the ranked calling list |
| [Customer Segmentation](customer-segmentation/) | Replace one-size-fits-all marketing with customer-specific strategies | Feature engineering, Gaussian mixture modeling, and cluster profiling | Five customer personas were identified and paired with targeted marketing recommendations |

## Tools and techniques

- Python and Jupyter Notebook
- pandas, NumPy, Matplotlib, and Seaborn
- scikit-learn classification, clustering, preprocessing, and model evaluation
- Exploratory data analysis and feature engineering
- Business-focused interpretation of model results

Open either project folder for its full methodology, findings, setup instructions, and presentation.
